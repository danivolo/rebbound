# Studio della frizione dinamica con simulazioni a N-corpi

L'obiettivo di questo progetto è di studiare la frizione dinamica che subisce un corpo di grande massa (buco nero) che si muove all'interno di una distesa di masse più piccole (stelle).
Per le simulazioni si utilizza il codice a N-corpi REBOUND, che integra il moto di particelle sotto la loro mutua influenza gravitazionale.

All'inizio abbiamo preso dimestichezza con il funzionamento base di REBOUND, eseguendo alcuni dei suoi tutorial base.
